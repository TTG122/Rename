# 05 · 快捷指令与双击背面

这是整个产品的入口。配一次，永久生效。

---

## 一、原理（30 秒看懂）

```
设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 「轻点记账」快捷指令
                                                      ↓
                                          快捷指令：截图 → App Intent
                                                      ↓
                                          轻点记账 App 在本机 OCR + 分类
                                                      ↓
                                              半屏面板，点一下入账
```

「轻点背面」是**系统级**手势，所以任何 App 里双击都能触发，我们不需要常驻后台——这也是它能通过 App Store 审核的前提。

---

## 二、搭建快捷指令（逐步）

### 第 1 步：新建

1. 打开系统「快捷指令」App（系统自带，删了去 App Store 装回来）
2. 右上角 `+`
3. 顶部点名字改成 `轻点记账`

### 第 2 步：加「获取图像」

> 这一步是拿你当前的屏幕内容。快捷指令里没有「直接读其他 App 屏幕」的能力，但「获取图像」可以从快捷指令的输入里拿到分享过来的图片。

1. 点「添加操作」→ 搜 `获取图像` → 选 **获取图像**（Get Images from Input）
2. 参数保持默认（从「快捷指令输入」获取）

### 第 3 步：加「轻点记账」

1. 再点「添加操作」→ 搜 `轻点记账`
2. 你会看到三条由 App 提供的操作：
   - **识别并记账**（这就是你要的）
   - 说一句就记账
   - 打开轻点记账
3. 选 **识别并记账**
4. 它有一个参数「截图」，点一下选 **快捷指令输入**（这样上一步的图像会自动传进来）

### 第 4 步：绑定到双击背面

1. iPhone → 设置 → 辅助功能 → 触控 → 轻点背面
2. 轻点两下 → 往下滚，在「快捷指令」区域找到 `轻点记账`
3. 选中

### 第 5 步：测试

回到任意 App，双击手机背面。你会感觉到一下轻震，然后：

- 如果识别置信度高且你开了「智能自动」→ 直接提示「已记账 ¥36.00」+ 撤销
- 否则 → 弹出半屏面板，推荐分类已选中，点一下就完成

## 三、拿不到截图怎么办（三个备用通道）

iOS 的沙盒决定了：**没有任何第三方 App 能在后台读另一个 App 的界面。** 所以下面这三条是设计的一部分，不是补丁。

### 通道 A：分享菜单

在微信/支付宝/相册里长按图片 → 分享 → 更多 → **轻点记账**。

- 扩展会把图片写进 App Group 收件箱
- 然后尝试唤起主 App 直接弹面板
- 即使唤起失败，下次打开 App 也会自动处理（不会丢）

### 通道 B：相册批量导入

App 首页 → `截图` 图标 → 一次选最多 10 张 → 逐张 OCR → 预览 → 确认导入。

### 通道 C：导入账单文件

微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账
支付宝：我的 → 账单 → 右上角 → 开具交易流水证明 → 导出 CSV

拿到 CSV 后：App → 设置 → 导入账单 → 选文件。几千行也能一次处理完，导入时会逐条查重。

## 四、排错

| 现象 | 检查 |
|---|---|
| 双击背面完全没反应 | 设置 → 辅助功能 → 触控 → 轻点背面，确认「轻点两下」选的是快捷指令而不是「无」 |
| 有震动但没弹面板 | 快捷指令里「识别并记账」的「截图」参数没接上一步的输出 |
| 提示「没收到截图」 | 同上；也检查快捷指令第一步是不是「获取图像」 |
| 面板弹出来但金额是 0 | 截图里没有可识别的金额；点金额手动输入 |
| 每次都弹重复提醒 | 该笔账单确实在库里；或者订单号被重复识别（可以在账单列表长按删除旧的那笔） |
| 双击后打开了完整 App | 说明走的是「打开轻点记账」那条快捷指令，换成「识别并记账」 |
| 面板不消失 | 点右上角 ✕；或确认保存后面板会自动收起（2 秒内） |

## 五、进阶：把截图也存一份

在快捷指令最后再加一步 `存储到相簿`。这样每笔账都有一张截图存档，方便以后核对。App 内不需要做任何改动。

## 六、进阶：只在自己常用的几个 App 里触发

iOS 的「轻点背面」是全局的，无法按 App 区分。如果你只想在微信里用，替代方案是「轻点背面 → 运行快捷指令 → 用『如果』判断当前 App」，但快捷指令拿不到前台 App 名（沙盒限制），所以做不到。

实际用起来，全局触发反而是优点：外卖、打车、银行、淘宝，全都能用同一套手势。
