# 00 · 最快装到手机（没有 Mac 也能做）

整个过程分 4 段，全程在你的 Windows 上完成，只有第 2 段由 GitHub 的 macOS 机器代劳。

```
① 把代码推到 GitHub  →  ② GitHub Actions 编译出 IPA  →  ③ Windows 上用 Sideloadly 签名  →  ④ 手机上信任证书
```

预计耗时：20 分钟（其中 3 分钟是等待编译）。

---

## ① 推到 GitHub

### 准备

- 一个 GitHub 账号（没有就注册，免费）
- 装 [GitHub Desktop](https://desktop.github.com/)（图形化，省掉登录配置的麻烦）

### 操作

1. 打开 GitHub Desktop → `File` → `Add local repository…`
2. 选目录 `D:\简记`
   （这个目录已经是 git 仓库并且已提交，Desktop 会直接识别，不会提示初始化）
3. 右上角 `Publish repository`
   - Name：`qingdianjizhang`
   - 取消勾选 `Keep this code private`（公开仓库的 macOS 构建额度完全免费；想私有也可以，额度也够用）
4. 点 `Publish repository`

> 命令行版（如果你更习惯终端）：
> ```bash
> cd /d/简记
> git remote add origin https://github.com/你的用户名/qingdianjizhang.git
> git branch -M main
> git push -u origin main
> ```
> HTTPS 推送要密码时，填的是 **Personal Access Token** 而不是账号密码：
> GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → 勾 `repo`。

## ② 让 GitHub 帮你编译

1. 打开仓库页面 → 顶部 `Actions`
2. 左侧选 `Build IPA` → 右侧 `Run workflow`
   - `flavor` 选 **sideload**（自签版，推荐）
   - 点绿色 `Run workflow`
3. 等 2~4 分钟，页面会出现一个绿色 ✔ 的运行记录
4. 点进这次运行 → 页面底部 `Artifacts` → 下载 **qingdian-sideload-ipa**
5. 解压，得到 `轻点记账-sideload.ipa`

> 如果这次运行是红色 ✘：点进去看 `Build sideload IPA` 那一步的日志，
> 把报错段落发给我，我按行改。日志末尾通常就是 `error: ...` 那一行。

## ③ 在 Windows 上签名并安装

### 装两个东西（只装一次）

1. **iTunes**：<https://www.apple.com/itunes/download/win64>
   ⚠️ 必须从上面这个官网地址下，**不要**用 Microsoft Store 版本——商店版不带 Apple 移动设备驱动，Sideloadly 会提示找不到设备。
2. **Sideloadly**：<https://sideloadly.io>（下载 Windows 版）

### 手机端设置

1. 数据线连电脑，手机上点「信任此电脑」
2. iPhone → 设置 → 隐私与安全性 → **开发者模式** → 打开 → 手机重启 → 重启后再确认一次

### 签名安装

1. 打开 Sideloadly
2. `IPA File` 选刚解压出来的 `轻点记账-sideload.ipa`
3. `Apple ID` 填你的 Apple ID
4. 点 `Start`
   - 如果弹密码框：平时用的密码 **不行**（开了双重认证的话），要去
     <https://appleid.apple.com> → 登录 → 登录与安全 → App 专用密码 → 生成一个，
     形如 `abcd-efgh-ijkl-mnop`，把这个填进去
5. 进度条走完，手机上就出现「轻点记账」了

## ④ 首次打开

1. 直接点图标会提示「不受信任的开发者」
2. 设置 → 通用 → VPN 与设备管理 → 点你的 Apple ID → **信任**
3. 回到桌面打开 App

## 装好之后

1. 走完 4 页引导
2. 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选「轻点记账」
   （快捷指令要先建：见 App 内「设置 → 双击背面设置教程」，或 `docs/05-快捷指令与双击背面.md`）
3. 找一张支付截图，双击手机背面试一次

## 一定要知道的三个限制

| 限制 | 说明 | 怎么办 |
|---|---|---|
| **7 天过期** | 免费 Apple ID 签的 App 只能用 7 天，之后点开闪退 | 重新用 Sideloadly 点一次 `Start`（账单数据不会丢）；或用 AltStore 自动续签 |
| **没有分享扩展** | 自签版剥掉了扩展，微信/支付宝里「分享到轻点记账」用不了 | 用 App 内「截图导入 / 相册批量导入」代替，功能不缺 |
| **没有桌面小组件** | 小组件依赖 App Groups，免费账号不支持 | 用付费账号（¥688/年）或 TestFlight 版本 |

如果你的 iPhone 系统版本在 14.0–17.0 之间且能装 **TrollStore**，可以做到永久签名，不受 7 天限制。

## 卡住了对照这张表

| 现象 | 原因 | 解决 |
|---|---|---|
| Actions 红色 ✘，日志有 `error:` | 代码编译错误 | 把日志发我，我改 |
| Actions 里没有 `Build IPA` | `.github` 目录没上传成功 | 用 GitHub Desktop 重新 push；或在网页上手动创建 `.github/workflows/build-ipa.yml` |
| Sideloadly 提示 `No device found` | 装的是 Microsoft Store 版 iTunes | 卸载，装官网版 iTunes |
| Sideloadly 提示 `Invalid Apple ID or password` | 双重认证下用了账号密码 | 生成 App 专用密码 |
| 安装到 99% 失败 | 手机上没开开发者模式 | 设置 → 隐私与安全性 → 开发者模式 |
| 装完打不开、闪退 | 证书 7 天过期 / 没信任 | 重新签 / 去 VPN 与设备管理里信任 |
| 提示 `Unable to install` | 手机上已有同名 App 但签名不同 | 先删掉旧的那个再装 |
